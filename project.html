Course Project

Nearest Cab Detection in Ride-Sharing Apps Using Dijkstra’s Algorithm

Project Overview

In this course project, we worked on a real-world problem inspired by modern ride-sharing platforms such as Uber and Ola. The objective was to identify the nearest available cab for a user in an efficient and accurate manner.

Problem Definition

Ride-sharing systems operate in dynamic environments where driver locations change continuously. A naïve distance-based approach may fail due to road networks, weighted paths, and real-world constraints.

Therefore, an algorithmic solution is required to guarantee optimal shortest path computation within a short response time.

Selection of Algorithms

As part of this project, we analyzed twelve algorithms including BFS, DFS, Bellman–Ford, Floyd–Warshall, Kruskal’s, Prim’s, Brute Force, Binary Search, Divide and Conquer, and the Greedy paradigm.

After comparison, we selected Dijkstra’s Algorithm because it guarantees optimal shortest paths in weighted graphs with non-negative edges and is widely used in navigation systems.

Algorithm Explanation

The user and all available cabs are modeled as nodes in a graph. Edge weights represent real-world distances calculated using the Haversine formula.

Dijkstra’s algorithm computes the shortest distance from the user node to all cab nodes, and the cab with the minimum distance is selected.

Implementation Summary

The project was implemented in C++ using a priority queue-based Dijkstra algorithm. The system is menu-driven and allows dynamic input of user and cab locations.

Complexity Analysis

Time Complexity: O((V + E) log V)

Space Complexity: O(V + E)

Compared to brute-force approaches, this method is more accurate and scalable for real-time systems.

Conclusion

This project demonstrated the practical application of Design and Analysis of Algorithms concepts in a real-world scenario. It strengthened our understanding of algorithm selection, complexity analysis, and system design.
